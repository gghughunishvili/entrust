# Entrust 13.0.0

- Works with **Laravel 13**, as well as Laravel 11 and 12. Install with `composer require gghughunishvili/entrust:^13.0`.
- **Laravel 13 needs PHP 8.3 or newer.** Laravel 11 and 12 still work on PHP 8.2.
- The README now has a table of every released version, with links to the docs for each one, so
  you can read the documentation that matches the version you installed.
- Upgrading from Laravel 11 or 12 needs no code changes.
