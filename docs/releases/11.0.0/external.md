# Entrust 11.0.0

- Works with **Laravel 11**. Install with `composer require gghughunishvili/entrust:^11.0`.
- Needs **PHP 8.2 or newer**.
- Laravel 6 to 10 stay on the previous version (`^10.0`).
- **Lumen is no longer supported.** Lumen users stay on `^10.0`.
- Simpler setup: the package registers itself, and middleware is set up in
  `bootstrap/app.php`, as Laravel 11 expects.
